# Quickstart: validar la spec 030

```bash
npm run lint && npm run build && npm test
npm run dev
```

1. Como administración: entrar a cada pantalla la primera vez → la ayuda se abre sola; cerrar con
   "Entendido"; volver → no se abre; "?" la abre.
2. Como personal en el mismo dispositivo: se abre sola de nuevo; no aparecen tareas de
   administración.
3. Ajustes → "Guía de uso": todas las pantallas visibles para el rol, desplegables.
4. Sin conexión: las ayudas se ven igual.
